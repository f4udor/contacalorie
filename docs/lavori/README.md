# Lavori

Una cartella per ogni issue lavorata dalle sessioni di Claude Code: `docs/lavori/<n>-<parola>/`, dove `<n>` è il numero dell'issue e `<parola>` la stessa del branch (es. `31-trend`).

- `TASKS.md`: i task, scritti dal pianificatore (`.claude/agents/pianificatore.md`).
- `DIARIO.md`: una riga per task chiuso, "Decisioni da confermare", "Non verificato".
- `REPORT.md`: il report di fine lavoro.

Regole in `CLAUDE.md`. Task, diario e report fino alla fase 8 stanno in `docs/archivio/`.
